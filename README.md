# FlowSync 🚀  
### Advanced Team Task Manager (Full-Stack Django + MySQL)

FlowSync is a production-ready full-stack Team Task Management web application built using Django, MySQL, Bootstrap, and Railway deployment.

It helps teams manage projects, tasks, teams, submissions, notifications, role-based access, and productivity workflows in a professional company-standard dashboard.

This project was built as a take-home assignment for a Full Stack Developer role and includes production deployment, REST APIs, role-based access control, advanced UI, admin management, and real-world SaaS-level architecture.
